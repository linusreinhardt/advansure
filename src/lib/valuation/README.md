# lib/valuation — Pauschalmethode (Schicht 2)

Reine TypeScript-Funktionsbibliothek zur Schadenshöhe (TU-05):
Raumgröße × Pauschalsatz pro Schadensgrad, Summenbildung.

- `rates.ts` — Pauschalsätze (z. B. 80/200/450/800 €/m²) und Default-Raumgrößen
- `calculate.ts` — reine Berechnungsfunktionen (gut testbar)

Bezug: PSP „Valuation-Service", TU-05.
